\# Local AI Voice Assistant



Локальный голосовой ИИ-ассистент на C# с модульной архитектурой, использующий Ollama, Vosk и Piper.



\## Возможности



\- Распознавание речи с микрофона через Vosk.

\- Генерация ответов локальной языковой моделью Llama 3.1 через Ollama.

\- Потоковая обработка ответов LLM.

\- Синтез русской речи через Piper.

\- Воспроизведение аудио через NAudio.

\- Обмен сообщениями между процессами через Named Pipes.

\- Хранение истории диалога в памяти.

\- Прерывание воспроизведения ответа при новом голосовом запросе.

\- Отображение метрик времени обработки запросов.



\## Архитектура



```text

&#x20;                 MainHost

&#x20;            (центральный модуль)

&#x20;                /    |    \\

&#x20;               /     |     \\

&#x20;       MicroWorker LLMWorker TTSWorker

&#x20;          Vosk      Ollama     Piper

```



\*\*MainHost\*\* — координация модулей, управление диалогом и воспроизведением звука.



\*\*MicroWorker\*\* — захват звука с микрофона, определение речевой активности и распознавание речи.



\*\*LLMWorker\*\* — взаимодействие с локальным Ollama API, поддержка потоковой генерации.



\*\*TTSWorker\*\* — синтез речи через Piper, очередь запросов и кэширование результатов.

\## Запуск



Для работы необходимы Windows, .NET SDK совместимой версии, Ollama с моделью `llama3.1`, модель распознавания Vosk и установленный Piper с русским голосом.



Каждый модуль представлен отдельным C# проектом. Перед запуском необходимо настроить локальные пути к моделям и исполняемым файлам в исходном коде.



Проект разработан и проверялся в локальном окружении. Автоматизированная установка и переносимая конфигурация пока не реализованы.



\## Статус



Учебный экспериментальный проект, демонстрирующий интеграцию локальных ИИ-моделей, многопроцессную архитектуру и асинхронное взаимодействие компонентов.
